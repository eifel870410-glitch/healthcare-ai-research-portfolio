## データセットと方法

- **患者教育：** ローカル環境でMIMIC-IV demo由来100行と病院承認済み教育文書225件を使用。元データと症例単位の派生物は公開していません。
- **胸部X線：** NIH由来正常画像、SIIM-ACR気胸例、水平反転した生成画像をローカルで使用。画像とDICOMは公開していません。
- **ASA分類：** ローカルファイルは患者単位の臨床属性を持つ訓練14,734行、テスト6,315行を含みます。来歴とライセンス確認まで全行を除外しています。
- **生物医学テキスト分類：** データセット名、ライセンス、クラス定義、完全な件数は `TODO` です。
- **MRI Radiomics：** 文献レビューのみで、独自の実験データセットはありません。
- **修士論文：** データと手法の詳細を意図的に非公開としています。

手法には、ローカルRAG、生物医学Transformer、構造化・テキスト特徴量設計、勾配ブースティングアンサンブル、CNN、UIプロトタイピング、批判的文献レビューが含まれます。臨床検証済みとは記載していません。

## エラー分析と学んだこと

- 引用形式と引用正確性は異なります。RAGの人手評価ではハルシネーションと誤引用の両方が記録されました。
- 胸部X線CNNは初期に単一クラスへ崩壊しました。再設計後の方向判定も、原画像と反転画像が分割をまたいだ場合、性能が過大評価される可能性があります。
- 気胸モデルの正常例と陽性例は異なるデータセット由来であり、収集元の差を学習した可能性があります。表示された陽性300例のうち82例が正常と予測されました。
- ASAの最終スクリプトはtransductive preprocessingと擬似ラベル付きテスト行を使用しており、その交差検証は独立した正解ラベル評価ではありません。
- 生物医学テキスト分類では内部検証と公開リーダーボードの挙動が一致せず、分布シフトを明示的に扱う必要性が示されました。

これらの失敗がヒューマンファクター研究への動機です。システムは不確実性と限界を可視化し、モデルが誤ったときの安全な回復を支援する必要があります。

## 限界

- 多くは後ろ向きの授業課題またはプロトタイプ開発です。
- 小規模、評価者1名、コンペ依存、データリーケージや分布シフトの可能性がある評価を含みます。
- 外部、前向き、多施設、較正、サブグループ、読影者研究は概ね未実施です。
- 一部プロジェクトではデータライセンスと個人貢献の文書化が未完了です。
- 公開repositoryは完全再現に必要な機微データを意図的に除外しています。
